# 教学楼四楼导览与示意导航

纯静态网站，直接由 GitHub Pages 托管。保留原楼层图、31 个可点击标记、搜索、手机定位读数和手动位置箭头。

## 使用

1. 搜索教室编号，或点击图上的房间、楼梯标记。
2. 点击“开始导航到这里”。若尚未标记室内位置，先点地图上自己所在的位置。
3. 查看蓝色示意路线；用“看起点”“看终点”切换视野，或点“结束”。
4. 移动到别处后，可在“我的位置”里重新标记起点，路线会重新计算。

手机提供的经纬度和估计精度持续显示在“我的位置”中。楼层图没有地理配准，也没有室内定位设备，因此图上的起点由学生手动标记；GPS 不会自动移动图上箭头。

## 结构与修改原因

| 阶段 | 文件 | 原因 |
| --- | --- | --- |
| 1：架构 | `index.html` | 保留现有静态页面及交互，只增加少量导航接口，避免整体重构。 |
| 2：地图模型 | `navigation-data.js` | 把通道节点、连接和 31 个目标入口与界面分开，便于以后现场校准。 |
| 3：路径算法 | `navigation.js` | 将手动起点吸附到最近的示意通道，按图像像素长度求最短路线。 |
| 4：路线显示 | `navigation-ui.js`、`index.html` | 在楼层图上叠加蓝色 SVG 路线，并接入目标选择、起终点查看和结束导航。 |
| 5：体验 | `index.html` | 手机端固定导航控件，并在页面内说明路线是示意路线。 |

地图坐标均为图片宽高的百分比。房间入口与通道连接依据上传的示意图推断，**未经现场核验**。路线不表示实际距离，也不覆盖跨楼层导航；到达目标时请以现场门牌和可通行路线为准。

## 检查与部署

运行 `node --test tests/*.test.cjs` 检查 31 个目标的入口、图连通性、路径可达性和最短路径行为。浏览器中还需检查桌面与手机的搜索、标记、导航、改起点和结束导航。

GitHub Pages 从 `main` 分支根目录发布，无构建步骤。新增脚本文件须与 `index.html` 一起发布；手动逐个上传时先上传脚本，最后上传 `index.html`。
